# RK Web Developer — Full Application

The project is split into independent folders so frontend, backend, database, infrastructure and documentation are easy to edit.

## Folder structure

```text
RK_Web_Developer_Full_Application/
├── frontend/                 # Public website and admin dashboard
│   ├── index.html
│   └── admin.html
├── backend/                  # Node.js / Express API
│   ├── src/                  # Routes, middleware, database access, config
│   ├── package.json
│   └── .env.example
├── database/                 # SQLite runtime data and schema reference
│   ├── data/                 # Database file is generated here
│   └── schema.sql
├── infra/                    # Prometheus and Grafana configuration
├── docs/                     # Project documentation
└── README.md
```

## Run locally

### 1. Start the backend

```bash
cd backend
npm install
```

Copy `backend/.env.example` to `backend/.env`. Set `JWT_SECRET` to a unique random value of at least 32 characters, and set a strong `ADMIN_USERNAME` and `ADMIN_PASSWORD`. Then run:

```bash
npm run dev
```

API health check: `http://localhost:4000/api/health`. The backend creates the SQLite database automatically at `database/data/rk-website.sqlite`.

### 2. Start the frontend

In another terminal:

```bash
cd frontend
python -m http.server 5500
```

Open `http://127.0.0.1:5500`. The public website uses `http://localhost:4000/api` by default. If your API runs elsewhere, edit `API_BASE_URL` in `frontend/index.html`. The admin dashboard lets you enter the API URL on its login screen; open `/admin.html`.

### 3. Folder responsibilities

- `frontend/`: website design and admin UI.
- `backend/`: API, authentication, validation, logging and server configuration.
- `database/`: SQLite file location and reference schema. Database file is generated at runtime.
- `infra/`: Prometheus and Grafana monitoring configuration.
- `docs/`: additional setup notes.

## Included functionality

- Responsive RK Web Developer website with white background and auto-sliding services, portfolio, pricing and testimonials.
- Public enquiry form and Refer & Earn form.
- Unique referral codes generated by the backend.
- Admin login and referral dashboard to list, update status and delete referrals.
- SQLite persistence, security headers, CORS, rate limiting, structured logs and Prometheus metrics.

## Security notes

- Never publish `.env`, JWT secrets, admin passwords, SQLite files or logs.
- Use HTTPS and set `FRONTEND_ORIGIN` to the exact deployed frontend origin(s).
- Change Grafana's demo password in `infra/docker-compose.monitoring.yml` before enabling monitoring.
- Referral rewards are not automatically calculated; the status `rewarded` is a manual admin status.

## Editable files

You can edit `frontend/index.html` for the website and `frontend/admin.html` for the dashboard. Backend API behavior is in `backend/src/routes/`; database creation is in `backend/src/db.js`.
